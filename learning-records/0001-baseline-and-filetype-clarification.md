# Established 3D Printing Baseline and File Format Clarification

The learner is starting from ground zero with an Original Prusa i3 MK3S (0.4mm nozzle) to print an ESP32-S3 case, initially confusing the `.STL` 3D geometry file with `.SRT` (subtitles). Clarifying the 3D pipeline (.STL -> PrusaSlicer -> .GCODE) and establishing that their file is `ESP32-S3.stl` establishes the baseline floor for manipulation and slicing instruction.
