# Authoritative C++ Engine on ESP32 with Thin Web Client

We need an object-oriented C++ project accessible on mobile and desktop without requiring users to compile or install native binaries. We decided that the ESP32-S3 runs the entire authoritative game engine, room management, and state logic in C++, serving a lightweight HTML5/WebSocket captive portal to connected devices that acts purely as a dumb terminal. This gives frictionless zero-install multiplayer access while keeping 100% of the game domain and OOP architecture strictly in C++.
